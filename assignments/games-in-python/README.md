# 📘 Assignment: Games in Python

## 🎯 Objective

Build engaging games using Python to practice loops, conditionals, user input, and logic. You'll create interactive applications that respond to player input and manage game state.

## 📝 Tasks

### 🛠️ Create a Hangman Game

#### Description
Develop the classic word-guessing game where players attempt to discover a hidden word by guessing letters one at a time. The game should track their progress and determine when they've won or lost.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and display current progress in underscore format (e.g., `_ _ _`)
- Track remaining incorrect guesses
- End with a win message when the word is correctly guessed
- End with a lose message when attempts are exhausted
- Display final word reveal after game ends


### 🛠️ Extend Your Game (Challenge)

#### Description
Enhance your Hangman game with additional features to make it more engaging and user-friendly.

#### Requirements
Completed program should:

- Provide hints to the player during gameplay
- Keep score across multiple rounds
- Allow difficulty levels that adjust word complexity
- Display a visual representation of hangman stages
- Validate user input and prevent duplicate guesses
